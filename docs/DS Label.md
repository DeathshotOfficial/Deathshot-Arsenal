# DS Label — Documentation

## 1. Overview

**Node Name:** `DS Label`  
**Category:** `☠️ Deathshot Arsenal/🎨 UI`  
**Class:** `DS_Label`  
**Purpose:** Minimalist, chromeless canvas title and zone header banner for organizing large ComfyUI workflows into visually distinct functional stages.

---

## 2. Core Capabilities

- **Chromeless Typography Banner:** Renders custom headers with adjustable font sizes, accent underlines, and theme coloring directly on the canvas without LiteGraph node body borders.
- **Visual Section Anchoring:** Provides clear visual signposts for complex multi-stage pipelines (e.g. `Stage 1: Base Generation`, `Stage 2: Face Detailer`, `Stage 3: 4K Upscale`).
- **Zero Computational Overhead:** Pure frontend canvas annotation node with no execution passes or sockets.
